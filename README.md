# B2 First · Práctica

App web para preparar el **Cambridge B2 First (FCE)** por partes, con explicaciones en español de cada respuesta.

- **Use of English** (Parts 1–4), **Reading** (Parts 5–7), **Writing** (6 tipos de texto)
- **Grammar** (9 temas) y **Vocabulary** (6 temas) con teoría en español
- **Simulacros** cronometrados con nota estimada en la escala de Cambridge
- **Mi progreso**: aciertos, puntos débiles, racha y copia de seguridad
- Speaking y Listening: próximamente

App: https://joseeseguraa.github.io/APPB2/

Cada parte incluye una guía (formato, qué evalúa, estrategia y errores típicos) y dos modos: **práctica** (sin tiempo, corrección inmediata) y **examen** (cronometrado).

```
npm install
npm run dev
npm test
```
