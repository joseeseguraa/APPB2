# B2 First · Práctica

App web para preparar el **Cambridge B2 First (FCE)** por partes, con explicaciones en español de cada respuesta.

- **Use of English** (Parts 1–4): disponible
- Grammar, Vocabulary, Reading, Writing, Speaking, Listening: en desarrollo

Cada parte incluye una guía (formato, qué evalúa, estrategia y errores típicos) y dos modos: **práctica** (sin tiempo, corrección inmediata) y **examen** (cronometrado).

```
npm install
npm run dev
npm test
```

El estado del proyecto y la hoja de ruta están en [CONTEXTO.md](./CONTEXTO.md).

> Material de práctica original. No es contenido oficial de Cambridge English.
